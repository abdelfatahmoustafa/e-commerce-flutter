# 🛒 Shoppy – Flutter E-commerce App

A fully functional e-commerce application built with Flutter enabling users to browse products, view details, manage cart, place orders, and manage their profile seamlessly with a clean responsive UI.

## ✨ Features

- **Authentication:** User registration and login with email and password.
- **Home Page:** Displays featured and new products, categories (Accessories, Clothes, Electronics), and an image slider.
- **Search:** Search products by name.
- **Product Details:** View detailed product information with image, price, and quantity selection to add to cart.
- **Cart Management:** View items in cart, update quantities, delete items, and view total price.
- **Orders:** View all previous orders with details.
- **Profile:** View user information (name, email, phone, address) with logout functionality.
- **Local Storage:** Persist user data, cart, and orders using shared_preferences.

---

## 🖥️ Main Screens

- **SplashScreen:** App splash screen.
- **LoginScreen:** User login page.
- **RegisterScreen:** User registration page.
- **HomeScreen:** Displays products, categories, search, and image slider.
- **CategoryProductsScreen:** Products filtered by category.
- **ProductDetailsScreen:** Product details with add-to-cart functionality.
- **CartScreen:** Shopping cart with items and total.
- **OrdersScreen:** User order history.
- **ProfileScreen:** User profile details.

---

## 🛠️ Tools & Libraries Used

- **Flutter:** Cross-platform mobile development framework.
- **http:** Handle API requests for login and registration.
- **shared_preferences:** Store user, cart, and order data locally.
- **image_picker:** Pick profile image during registration.
- **smooth_page_indicator:** Page indicators for sliders.
- **cupertino_icons:** iOS icon set.
